## Принятые решения
- Решение: работаем в `main` без feature-веток, один коммит на починку. Причина:
  один разработчик, worktrees плодили копии приложения и путаницу. Альтернатива:
  ветка на фичу — только для больших рискованных слайсов, с предупреждением.
- Решение: `main` влит до ручной приёмки, вопреки правилу плана стабилизации.
  Причина: `main` содержал GC, удалявший файлы File Cards; держать его хуже.
- Решение: оркестратор (Opus) + агенты-исполнители (Sonnet), один пишущий агент
  за раз в общей папке; параллельно — только если области кода не пересекаются
  и агент добавляет в индекс только свои файлы.
- Решение: id вложенного содержимого при `duplicate_board` генерирует backend
  (ADR-0009) — единственное исключение из «id генерирует фронт».
- Решение: ярлык доски — отдельный kind `board_shortcut`, не владеет доской,
  identity читается JOIN'ом, каскад в Trash тем же batch, поиск не индексирует (ADR-0010).
- Решение: внутренний буфер карточек в памяти вместо системного clipboard —
  WKWebView не принимает кастомный mime.
- Решение: `.md` рендерится на backend в HTML и показывается тем же sandboxed
  iframe, что `.html`.
